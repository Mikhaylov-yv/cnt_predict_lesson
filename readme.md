# Контейнерный предиктор на основе трансформеров

Полный pipeline для предсказания состояний и локаций контейнеров с использованием архитектуры трансформеров.

## Описание

Система предсказывает будущие состояния и локации контейнеров на основе исторических данных о транзакциях, агрегатах и заявках. Использует архитектуру трансформера для обработки временных последовательностей.

## Структура данных

### Входные данные:
- **cnt_events.csv**: Транзакции контейнеров (dt, event, cnt_id, cnt_type, location_name, end_location_name)
- **transport_requests.csv**: Заявки на перевозку (Дата_заявки, Планируемая_дата_отправления, Количество_контейнеров, Тип_контейнера, Локация_отправления, Локация_назначения)
- **cnt_empty_count.csv**: Агрегаты по типам и локациям (dt, Москва_20, Владивосток_20, Санкт-Петербург_20, Москва_40, Владивосток_40, Санкт-Петербург_40)

## Архитектура

### 1. Обработка данных
- Создание календаря всех дат в диапазоне
- Преобразование транзакций в daily-snapshots для каждого контейнера
- Добавление глобальных признаков из агрегатов и заявок
- Объединение локальных и глобальных данных

### 2. Модель трансформера
- **Локальные признаки**: состояние, локация, тип контейнера, время
- **Глобальные признаки**: агрегаты, заявки, временные признаки
- **Архитектура**: Multi-head attention, 6 слоев, 8 голов внимания
- **Предсказание**: состояния и локации на горизонте 7 дней

### 3. Обучение
- Cross-entropy loss для состояний и локаций
- Adam optimizer с learning rate scheduling
- Валидация на отдельной выборке

## Использование

### Установка зависимостей и запуск обучения:

```bash
# Создание виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск обучения
python transformer_predictor.py
```

Или используйте готовый скрипт:

```bash
chmod +x run_training.sh
./run_training.sh
```

### Анализ результатов:

```bash
python inference_analysis.py
```

## Файлы

- **transformer_predictor.py**: Основной код обучения модели
- **inference_analysis.py**: Инференс и анализ результатов
- **requirements.txt**: Зависимости Python
- **run_training.sh**: Скрипт для запуска обучения
- **container_transformer_model.pth**: Сохраненная модель (создается после обучения)

## Особенности реализации

### Обработка данных:
- Создание daily-snapshots с переносом состояний
- Добавление lagged features (заявки на будущее)
- Нормализация глобальных признаков
- Кодирование категориальных переменных

### Модель:
- Embedding слои для всех категориальных признаков
- Объединение локальных и глобальных признаков
- Multi-head attention для улавливания зависимостей
- Отдельные головы для предсказания состояний и локаций

### Обучение:
- Скользящие окна для создания последовательностей
- Batch processing для эффективного обучения
- Learning rate scheduling
- Валидация и сохранение лучшей модели

## Результаты

Модель предсказывает:
- Состояния контейнеров (free, loading, loaded, arrived_loaded, unloading)
- Локации контейнеров (Москва, Владивосток, Санкт-Петербург)
- Вероятности для каждого предсказания
- Агрегированные прогнозы по всем контейнерам
